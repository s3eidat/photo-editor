# Lane: vector

Files: `js/vector/*.js`, `js/vector/vector.css`. Hook lines in shared files are marked `// lane:vector`
(the key-handler and `ED.ui.MENUS/TOOLS/w` lines are byte-identical to the selection lane's, so merges stay clean).
Self-test: `js/vector/vtest.js` extends `window.S3_SELFTEST` (path booleans, curve maths, shape rendering, round trips).

| Feature | Status | Notes |
|---|---|---|
| Shape tools as live vector layers | done | Rectangle (corner radius), ellipse, triangle, polygon (3–100 sides), star (points + indent %), line with start/end arrowheads (width, length, concavity), arrow, 24 custom shapes drawn for this app. Fill colour / none / fill opacity; stroke colour, width, dash presets + custom dash pattern, inside / centre / outside alignment, caps, corners. All editable later in Properties; "Edit as path" turns a shape into a free path. Saved in .s3photo (fields whitelisted and clamped on open). |
| Pen tool (bezier) | done | Click = corner, drag = smooth handles (Alt breaks, Shift = 45°), click first anchor to close, Enter/Esc ends, Alt-click last anchor = cusp, click an open end to continue it, auto add/delete on the path, rubber band. "Shape" mode draws into a new or the current shape layer with New / Combine / Subtract / Intersect / Exclude; "Path" mode draws the work path. Every anchor is one undo step. |
| Curvature pen | done | Curve flows through each click (auto-smooth anchors); double-click / Alt-click toggles corner; drag a point to move it; click a segment to add one. |
| Freeform pen | done | Freehand drag, least-squares cubic fitting with a curve-fit tolerance (screen px); closes when it ends near its start. |
| Add / delete / convert anchor | done | Separate tools in the pen group (P, Shift+P cycles) and pen modifiers. Convert: click toggles smooth/corner, drag pulls handles, drag a handle breaks it. |
| Path selection / direct selection | done | (A, Shift+A.) Components: select (Shift adds), move, Alt-drag copy, delete, set combine mode, Merge (real boolean geometry). Anchors: click / marquee / Shift, drag anchors, handles (smooth stays smooth, Alt breaks), drag a curve to reshape it, Delete, arrow nudge. Clicking another shape layer's outline selects it. |
| Paths panel | done | Work path (italic), saved paths, the selected shape layer's outline. New, save work path / rename (double-click), duplicate, delete, select (the pen and selection tools then edit it). Fill path (colour, opacity), stroke path (brush / pencil / eraser tip, optional taper), load as selection (feather, anti-alias, new/add/subtract/intersect; Ctrl+Enter), make work path from selection (tolerance; traced and curve-fitted in a worker), path to shape layer. Alt-click the panel buttons for the option dialogs; also in Select and Edit menus. Saved with the project. |
| Point text and paragraph text | done | Click = point text, drag = paragraph box (word wrap, long words break, overflow flagged with a red + and hidden lines), drag the box handles with the type tool to resize without scaling; convert point ⇄ paragraph. Free transform scales boxes; non-uniform scaling becomes horizontal / vertical character scale. |
| Character panel | partial | Font, weight 100–900, size, leading, tracking (‰ em), kerning (font metrics / none), baseline shift, horizontal / vertical scale, colour, faux bold, faux italic, italic, all caps, small caps, superscript, subscript, underline, strikethrough. Settings apply to the whole layer (no per-character runs); optical kerning and language/anti-alias options skipped. |
| Paragraph panel | partial | Left / centre / right, justify with last line left / centre / right, justify all; indent left / right / first line; space before / after; direction. Hyphenation skipped. |
| Transform: skew, distort, perspective | done | Edit › Transform: …, or the Mode list while in Free transform. Skew slides edges, Distort moves corners / edges freely, Perspective mirrors the partner corner. Live preview from a reduced copy; the result is resampled exactly in a worker (dense mesh, bilinear, coverage anti-aliasing), mask included. Shape layers stay vector (anchors mapped). |
| Warp (mesh) | done | 4 × 4 bezier mesh: drag corners (carry their tangents), tangent / inner points, or grab anywhere inside (least-change drag). Warp styles: arc, arc lower / upper, arch, bulge, shell lower / upper, flag, wave, fish, rise, fisheye, inflate, squeeze, twist with bend and horizontal / vertical distortion; "Edit points" turns a style into an editable mesh (least-squares fit). |
| Liquify | done | Filter › Liquify… (Ctrl+Shift+X): full-screen workspace with forward warp, reconstruct, smooth, twirl (Alt reverses), pucker, bloat, push left (Alt = right), freeze / thaw mask (outside a selection starts frozen; freeze all, thaw all, invert), hand, zoom; brush size, density, pressure, rate; reconstruct-all slider, restore all; show mask / mesh; its own undo (Ctrl+Z, 8 strokes); [ ] size. Works on a ≤1600 px displacement field for speed; OK resamples the full layer in a worker. Face-aware tools skipped (needs face detection). |
| Path operations (unite, subtract, intersect, exclude) | done | Per component (pen options for new components, path-selection options or Properties for existing ones), rendered live with exact polygon booleans (split at every crossing + winding classification, flattened curves); "Merge" bakes them into one outline. Known-answer self-tests for areas, holes, touching and identical shapes. |
| Warp text | done | Layer › Warp text…, the Warp button in the type options, or Edit › Transform › Warp on a text layer. 15 styles (shared with image warp), bend, horizontal / vertical distortion, horizontal / vertical orientation; live preview, one undo step, Esc cancels. Text stays editable; drawn by meshing the laid-out text (aspect-correct arcs). Saved in projects. |
| Text on a path | done | With the type tool, click the current path or a selected shape's outline. Letters follow the curve (Arabic and other right-to-left text by whole words so it stays joined), alignment sets where the text sits on the start point; Properties: start offset, flip to the other side, release from path. Moves, transforms and saves with the layer; overflow past an open path's end is hidden and flagged. |
| Glyphs panel | done | Side panel (also Layer › Glyphs…): punctuation & symbols, Latin, accented Latin, Greek, Cyrillic, Arabic (incl. Persian letters, Arabic-Indic digits, marks), currency, arrows, maths, shapes, symbols & dingbats, box drawing, recently used; shown in the current text's font; click inserts at the caret (starts editing the selected text layer if needed). OpenType alternates per glyph skipped (no font-table access in the browser canvas). |
| Content-aware-style scale (seam carving) | done | Image › Smart resize… (Ctrl+Shift+Alt+C): narrower / wider and shorter / taller by removing or doubling the least noticeable seams; protect the selection, protect skin tones, optionally resize the canvas; live thumbnail preview. Seams are found on a reduced copy (≤1200 px) in the worker, then removed or doubled at full size. |
