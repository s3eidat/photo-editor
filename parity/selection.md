# Lane: selection

| Feature | Status | Notes |
|---|---|---|
| Quick selection brush | done | New tool next to the magic wand (W toggles them). Paint over an area: it grows into connected, similar colours from the strokes and stops at edges (k-means palette of the painted colours, adaptive colour/edge thresholds, worker), live while dragging. New/Add/Subtract (switches to Add after the first stroke; Shift adds, Alt subtracts), size, sensitivity, all layers, smooth edges (guided filter), Select subject button. |
| Refine selection workspace | done | Select › Refine selection… (Ctrl+Alt+R, or "Refine…" on selection tools' option bars). Edge detection radius + smart radius (colour guided filter in a band around the edge; hard image edges get a narrower band), refine-edge brush for hair/fur, add/remove brush (Alt), smooth, feather, contrast, shift edge, views (overlay with opacity, on black, on white, black & white, on transparency, marching ants), decontaminate colours + amount, output to selection / layer mask / new layer / new layer with mask (original hidden). Preview at ≤1600 px in the worker, final result at full size; Ctrl+Z undoes brush strokes inside the workspace. The name "Select and Mask" is not used. |
| Colour range | done | Select › Colour range…: pick colours on the canvas (Shift adds, Alt removes) with fuzziness (Lab distance) and localized colour clusters (range), or preset ranges: reds, yellows, greens, cyans, blues, magentas, highlights, midtones, shadows, skin tones; invert; replace/add/subtract/intersect with the current selection. Live overlay + grey thumbnail at ≤1200 px, full-size result on OK. |
| Quick mask mode | done | Q, Select › Quick mask mode, or the button under the colours. The selection becomes a red film over unselected areas; brush, eraser, gradient, fill and paint bucket edit it (black masks, white selects, grey partial); Q again makes it a selection. Every step undoes. Works through a hidden helper layer whose mask is the quick mask (never drawn into the picture or exports; a project saved in quick mask reopens with the selection). Film colour/opacity are fixed (red, 50%). |
| Transform selection | done | Select › Transform selection: free-transform handles and W/H/angle/flip fields act on the selection outline only (live transformed marching ants); Enter/Apply, Esc, undo. No skew/perspective (the vector lane owns those transforms). |
| Modify: border, smooth | done | Select › Border… / Smooth…. Border is a band straddling the edge from an exact distance transform (anti-aliased); smooth is a majority filter (removes specks, rounds corners). Worker: `js/select/worker.js`. |
| Select subject / remove background | done | Select › Subject (also a button on the selection tools' option bar) and Layer › Remove background (adds a layer mask). Same on-device AI as bg-remover: U²-Net small via ONNX Runtime Web, engine + model (~16 MB) fetched from this site on first use only, then cached (service worker) for offline. Mask predicted at 320 px, edges snapped with a guided filter at up to 1600 px, then scaled to the document. CSP gains `'wasm-unsafe-eval'` (WebAssembly compile only; JS eval stays blocked). |
| All 27 blend modes | done | Normal, dissolve, darken group (darken, multiply, colour burn, linear burn, darker colour), lighten group (lighten, screen, colour dodge, linear dodge (add), lighter colour), contrast group (overlay, soft/hard/vivid/linear/pin light, hard mix), difference, exclusion, subtract, divide, hue, saturation, colour, luminosity. 16 run natively on the canvas; 11 in JS (`PIX.blendRegion`, byte lookup tables). Grouped menu, Shift+Alt+letter shortcuts, Shift +/− steps through modes (when a non-painting tool is active). Self-test checks every mode in the compositor against the per-pixel maths. |
| Fill opacity | done | "Fill" slider under Opacity; equals opacity until layer styles exist (styles stay at full strength). Saved in projects, undoable. The "special 8" fill behaviour of some modes is not replicated. |
| Layer groups | done | Nested groups (kind `group`, members point to it with `parent`), collapse/expand, pass-through by default or any blend mode + opacity + group mask (isolated), Ctrl+G / Ctrl+Shift+G, New group button, drag layers in/out of groups, Ctrl+[ ] walks in and out of open groups, move / free transform / flip / hide / lock / duplicate / delete / merge with members. Multi-select in the panel (Ctrl/Cmd+click, Shift+click) for grouping, duplicating, deleting and merging. |
| Clipping masks | done | Layer › Create / release clipping mask (Ctrl+Alt+G) or Alt+click a layer row. Clipped layers show only inside the base's pixels (soft edges kept), keep their own blend/opacity/fill; the base's blend and opacity apply to the stack; groups can be bases or clipped. Panel marks clipped layers with an arrow and underlines the base. |
| Adjustment layers | done | Layer › New adjustment layer… or the half-circle button: brightness/contrast, levels (with auto), curves (per channel), exposure, hue/saturation, vibrance, colour balance, black & white, threshold, invert, desaturate — plus any colour op other lanes add to `ED.ADJ` (specs marked `filter: true` are left out). Settings edit live in Properties (one undo step per pause), the mask starts from the selection, painting/filling targets the mask, opacity blends the effect, clipping limits it to one layer, merge down bakes it. Top-level pixel work is cached between frames. |
| Layer styles | done | Drop shadow, inner shadow, outer glow, inner glow (edge/centre), bevel & emboss (inner, outer, emboss, pillow; depth, direction, size, soften, angle, altitude, highlight/shadow modes), satin, colour overlay, gradient overlay (linear/radial/reflected), pattern overlay (7 patterns drawn in code), stroke (outside/inside/centre). Floating live panel (Layer › Layer style…, fx button, double-click a layer row), show/hide all, copy / paste / clear style (works on several picked layers). Shadows/glows draw behind with their own blend modes, interior effects ignore Fill, styles follow the layer mask. Rendered from exact distance transforms + blurs into a cached padded box; computed at lower resolution only while painting the styled layer. No global light, contours or per-effect noise yet. |
| Fill layers | done | Layer › New fill layer…: solid colour, gradient (linear/radial/reflected, angle, scale, reverse, fade to transparent) or pattern (7 code-drawn patterns, colour, background, scale). Edited live in Properties, mask from the selection (selection then cleared, like adjustment layers), painting goes to the mask, blends/clips/styles like any layer, rasterize to pixels. |
| Align / distribute | done | Move tool options bar icons + Layer menu: align left / horizontal centres / right / top / vertical centres / bottom; distribute left edges / horizontal centres / equal horizontal or vertical gaps. Several picked layers align to their common box; one layer aligns to the selection (or the canvas). Groups move with their members, one undo step. |
| Linked layers | done | Layer › Link / Unlink layers or the chain button: picked layers move together (drag and arrow keys); link icon in the panel; saved in projects. Free transform does not yet carry linked layers. |
| Stamp visible / merge copy | done | Ctrl+Shift+Alt+E stamps everything visible into a new layer; Ctrl+Alt+E merges a copy of the picked layers; originals stay. |
| Channels panel, save/load selection | done | Channels panel (under Layers): RGB, Red, Green, Blue (click to preview one colour channel in grey) and alpha channels. Select › Save selection… (new channel, or replace/add/subtract/intersect into one) and Load selection… (invert, operation); Ctrl+click a channel thumbnail loads it (Shift adds, Alt subtracts); click an alpha channel to paint it (red film), rename by double-click, delete. Alpha channels are hidden helper layers (kind `channel`), so they undo and save in projects. Editing a single colour channel is not supported (preview only). |
| Smart layers + smart filters | done | Layer › Convert to smart layer (one layer, several picked layers or a group become one smart layer). Keeps the source pixels and a transform matrix: free transform (box follows the layer's rotation), flips, moves, align, crop/canvas size, rotate canvas and image size only change the matrix, so shrinking and enlarging again loses nothing. Smart filters (every filter/adjustment without a custom panel, plus invert/desaturate/sharpen) are added, edited, hidden and removed in Properties; reset transform; rasterize. Saved in projects (source in the layer's image slot). No "edit contents" (nested document) yet. |
| Vector masks | done | Layer › Vector mask from selection (traces the selection outline into simplified polygons), ellipse or rectangle (from the selection box), rasterize to the pixel mask, delete. Properties: enable, invert, feather. Resolution-independent; moves, transforms, crops and scales with the layer; works on groups; applied before layer styles. Path format `L.vmask.paths = [{closed, pts:[[x,y,inX,inY,outX,outY]…]}]` (doc coords, absolute handles) so the vector lane's pen/path tools can create or edit them. No on-canvas path editing in this lane. |
| Grow, similar | done | Select › Grow / Similar use the Magic wand tolerance and "All layers" setting; colours are matched against every colour already selected (binned 64 levels/channel, max-channel distance like the wand). |

## Hooks this lane added to shared files
All marked `// lane:selection` (or `<!-- lane:selection -->`).
- `index.html`: script tags for `js/select/*` and `js/layers/*`, after `ui.js`, before `app.js`.
- `js/ui.js`: `ED.ui.MENUS`, `ED.ui.TOOLS`, `ED.ui.w` (option/dialog widgets) exposed so lanes can add menu items, tools and dialogs.
- `js/core.js`: `PE.drawHook` (lane compositor, returns false to keep the original loop), `PE.snapExt` / `PE.restoreExt` (extra layer fields in undo snapshots), `PE.kindsExt`, `PE.parseExt`, `PE.saveExt`, `PE.openExt` (extra layer kinds/fields in .s3photo files; layers also keep their id as `uid`).
- `js/core.js`: `PE.surfaceExt[kind]`, `PE.vboxExt[kind]` (pixels / box of new layer kinds).
- `js/editor.js`: `PE.editableExt` (extra editing rules), `PE.shiftExt` (move members / linked layers), `PE.xfExt[kind]` (transform of new kinds).
- `js/editor.js`: `PE.xfAny(L, m, xf)` runs for every layer in transformLayer (vector masks).
- `js/ui.js`: `ED.ui.propsTail(P, L)` at the end of Properties for built-in layer kinds.
- `js/ui.js`: `ED.ui.layersExt` (Layers panel as a tree), `ED.ui.propsExt` (Properties for new kinds), `PE.dupExt`, `PE.removeExt`, `PE.mergeExt`, `PE.moveExt` (layer operations that understand groups).
- `js/ui.js`: `ED.ui.optsTail` — array of `f(tool, items)` that append controls to the tool options bar.
- `index.html`: CSP `script-src 'self' 'wasm-unsafe-eval'`; vendored `lib/ort.*` (ONNX Runtime Web, MIT) and `models/u2netp/` (Apache-2.0), see `models/LICENSES.md`.
- `js/editor.js`: `PE.offsetExt(L, dx, dy)` in crop/canvas size and `PE.scaleExt(L, kx, ky)` in image size, for layer kinds with their own geometry.
- `js/editor.js`: `ED.emit("overlay", {c, docPath, dpr})` at the end of the overlay paint, so lanes can draw previews.
- `js/editor.js`: tools in `ED.TOOLS` flagged `brush: true` get the round brush cursor.
- `js/ui.js`: `ED.ui.keys` — array of key handlers `f(e) -> true if handled`, run before the built-in shortcuts.
- Self-test: `PE.sx.tests` (array of `async (ok, near) => {}`) runs after the app's own `S3_SELFTEST`; no change to `app.js`.
