# Lane: files

| Feature | Status | Notes |
|---|---|---|
| PSD open | done | File › Open (or drop) a `.psd`. Layers keep pixels, position, name, visibility, lock, opacity, blend mode, fill opacity and clipping (when the selection lane's model is present), layer masks (default colour, disabled flag) and vector masks (rasterised into the mask). Point and paragraph text stay editable when they use one style (font, size, colour, bold/italic, alignment, leading, rotation, flip; paragraph text is wrapped to its box); mixed-style, warped, vertical and on-path text keep their pixels. Live rectangles, rounded rectangles and ellipses stay editable shapes; other vector shapes keep their pixels. Groups are flattened into plain layers (folded visibility/opacity) until the selection lane's groups land, then they map 1:1. 8/16/32-bit, RGB, greyscale, indexed and bitmap files open (16/32-bit are converted to 8-bit). Resolution and guides are kept. A file with no layers opens its merged image; one with more than 100 layers opens merged with a message. Parsing runs in a worker (`js/files/psd-worker.js`). Checked against 70 sample files from the ag-psd test suite (not committed). |
| PSD save | done | File › Save as PSD…. Writes every layer with its pixels, masks, opacity, blend, visibility, lock, fill opacity, clipping; text layers as real text (font PostScript name, size, colour, faux bold/italic, leading, alignment, rotation) plus the rendered pixels; shapes as vector shape layers (path + fill + stroke; rectangles/ellipses also as live shapes); groups nested when present; merged image, resolution and guides. Our exact text/shape settings ride in XMP, so a round trip through this app is pixel-identical; they are only used while the file's own data still matches. Verified with an independent reader (psd-tools). |
| Export as | done | File › Export as… (also the Export button, Ctrl+Shift+Alt+W; Export selection… opens it with "Only the selection"). Formats PNG, JPG, WebP and AVIF (when the browser can encode them), TIFF, BMP. Quality, TIFF compression (none / LZW / ZIP), transparency or a matte colour, size by width / height / percent with 25–300% presets, smooth or pixel-art (nearest) resampling, selection only. Live preview of the encoded result (fit or 100%) with its real file size. Metadata: none by default (nothing about the camera, place or edits is ever written), or author + copyright as XMP in JPG/PNG/TIFF plus PNG text chunks and TIFF Artist/Copyright tags. Settings are remembered. Checked with Pillow: TIFF (all compressions), BMP, PNG and JPG decode pixel-exact / with metadata. |
| Quick export | done | File › Quick export as <format>: the whole image at 100% with the last Export-as settings, no dialog. |
| TIFF export | done | Own encoder (`js/files/encode.js`, in a worker): 8-bit RGB/RGBA (unassociated alpha), none / LZW / Adobe-deflate with horizontal predictor, resolution, author/copyright tags. Flattened (layered TIFF is not written). |
| TIFF open (extra) | done | Own baseline reader: strips or tiles, none / LZW / ZIP / PackBits, predictor, 1/4/8/16-bit grey, palette, RGB(A), associated alpha; resolution kept. CMYK, JPEG-in-TIFF, planar and float TIFFs give a clear message. |
| BMP export (extra) | done | 24-bit, or 32-bit with alpha (V4 header). |
| Export layers to files | done | File › Export layers to files…: visible, all or the selected layer; any export format; trimmed to each layer's pixels or at canvas size; keep or drop layer opacity; transparency; prefix and scale. One file downloads directly, several come as one .zip (UTF-8 names). |
| Trim / Reveal all | done | Image › Trim… (transparent pixels, top-left or bottom-right colour; choose sides) and Image › Reveal all (canvas grows to fit every layer's pixels, text and shapes). One undo step each. |
| Rulers | done | View › Rulers (Ctrl+R). Top and left rulers in px, in, cm, mm, pt, pc or % (click the corner square to change; uses the document resolution, 72 ppi if none), follow zoom and pan, show the pointer position. |
| Guides | done | Drag from a ruler (Alt flips the direction, Shift snaps to ruler ticks); move with the Move tool, drag back onto the ruler to delete; View › New guide…, New guide layout… (columns, rows, gutters, margins, live preview), Clear guides, Lock guides (Ctrl+Alt+;), show/hide (Ctrl+;). Undoable, saved in projects and PSD files, read from PSD files. |
| Grid | done | View › Grid (Ctrl+'), Guides & grid settings… (spacing in any unit, subdivisions, grid and guide colours). |
| Snapping | done | View › Snap (Ctrl+Shift+;) and Snap to guides / grid / layers / document edges. Moving a layer or selected pixels snaps its edges and centre; marquee, crop, shape, gradient, text placement and transform handles snap the pointer; dragged guides snap to the grid and layer edges. Hold Ctrl while dragging to skip snapping. |
| Smart guides | done | View › Smart guides: while moving, magenta lines show when the layer's edges or centre line up with another layer or the canvas centre (and it snaps there). |
| Document tabs | done | Every new / opened document gets a tab above the canvas; each keeps its own history, zoom and scroll. Window menu: next / previous (Ctrl+Alt+→ / ←), close (Ctrl+Alt+W; also middle-click a tab), close others, close all, and the list of open documents. Leaving a tab autosaves it; tabs come back after a reload and load when clicked. Background tabs' oldest history steps are trimmed first when memory runs short. (Ctrl+Tab and Ctrl+W belong to the browser.) |
| Navigator | done | Window › Navigator. Thumbnail with the visible area outlined; click or drag to scroll; zoom slider, buttons and % field. |
| Histogram | done | Window › Histogram. Colours (R/G/B overlaid), luminosity or one channel; entire image or selected layer; inside the selection when there is one. Mean, std dev, median, pixel count; hover for level, count, percentile. Counted in the worker on at most ~1 MP ("sampled" is shown when reduced). |
| Info | done | Window › Info. Colour under the pointer (RGB + HSB / Lab (D50, matches editor conventions) / simple CMYK, hex, opacity), all layers or the current one; pointer position in ruler units; marquee / crop / transform size while dragging, selection size; document size, ppi and print size. |
| Panels (part 1) | done | Side panels register with `WS.panel` (Properties, Layers and History included); Window menu shows/hides each; open/closed state and order are remembered. Docking and saved workspaces: see below. |
| Preferences | done | Edit › Preferences… (Ctrl+K): history states and history memory (automatic by device memory, or a fixed MB), ruler units, resolution for new documents, guide / smart-guide / grid colours, grid spacing and subdivisions, tool hints on/off, reset panels, reset everything. Applies to open tabs at once. |
| Customizable shortcuts | done | Edit › Keyboard shortcuts… (also the keyboard button and `?`): every menu command and tool, search, click and press keys, Backspace clears, conflicts flagged and moved, per-row Default, Reset all, Export / Import a .json set (validated). Custom keys win over built-in ones; a built-in shortcut that was moved away is freed. Menus show the custom keys. |
| Print with crop marks | done | File › Print… (Ctrl+P): paper (A3/A4/A5, Letter, Legal, Tabloid, 4×6, 5×7, 8×10), orientation (auto/portrait/landscape), fit to page / document size (uses the ppi) / scale %, margin, bleed; corner crop marks, centre marks, registration targets, label; live preview with the effective ppi and warnings. The page is rendered up to 300 ppi and printed through the browser (which can save a PDF); `@page` sets the paper size and zero margins. |

Not supported (by the vendored parser, ag-psd 31.0.3): CMYK, Lab, multichannel and duotone colour modes (a clear message asks to convert to RGB first), PSB large-document files. Layer styles and adjustment layers are reported as left out until the selection/adjust lanes add them, then they get mapped.

## Hooks this lane added to shared files
All marked `// lane:files` (or `<!-- lane:files -->`); where the selection lane already added the same hook the line is identical, so merges are clean.
- `index.html`: `js/files/files.css` stylesheet, script tags for `js/files/*` (and later `js/workspace/*`), before `app.js`; `.psd` in the open dialog's accept list (other extensions are added at run time).
- `js/ui.js`: `ED.ui.openExt(files, asLayers)` called from `openFiles` (extra file formats); `ED.ui.exportExt(selOnly)` at the top of `exportDialog` (the Export-as dialog replaces the old one); same `ED.ui.MENUS` / `ED.ui.w` / `ED.ui.keys` line as the selection lane.
- `js/editor.js`: `ED.ovlExt` (overlay painters), `ED.downExt` (pointer-down before tools: guides…), `ED.snapPt` (pointer snapping), `ED.snapMove` (move snapping), `ED.cursorExt`.
- `js/core.js`: `PE.docSaveExt` / `PE.docOpenExt` (document-level fields such as guides in `project.json`, validated on open).
- Self-test: `PE.files.tests` (array of `async (ok, near, px, solid) => {}`) run after `S3_SELFTEST` by wrapping it; no change to `app.js`.

## Third-party code
- `lib/ag-psd.js`: ag-psd 31.0.3 browser bundle (MIT), minified, with pako, base64-js, buffer (MIT) and ieee754 (BSD-3). Licences in `lib/ag-psd.LICENSE`. Loaded only by the PSD worker (or lazily on this thread if workers are unavailable).
